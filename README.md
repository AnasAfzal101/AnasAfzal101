## 🛠️ What I offer

**AdMob Ads Integration for Your Unity Android Game** ([on Contra](https://contra.com/anas_afzal_yp528ik6), 3-day delivery)

You get the same setup you can see in my demo below:

- **Banner, interstitial and rewarded ads**, using Google's official Unity plugin
- **Safe callbacks:** every ad event is moved to Unity's main thread before it touches your score or UI
- **Preloading and retry:** the next ad loads in the background, and failed loads retry with a backoff instead of spamming requests
- **Tested with Google's test ads first**, so your AdMob account stays safe

## ⭐ Featured project: AdMob Integration Demo

[![AdMob Integration Demo](https://github.com/AnasAfzal101/AdMob-Demo/raw/main/docs/cover.png)](https://github.com/AnasAfzal101/AdMob-Demo)

A small Unity 6 tap game that shows a complete AdMob setup on Android, tested on a real device:

| Ad type | How it works |
|---|---|
| Banner | Adaptive banner anchored at the bottom of the screen |
| Interstitial | Every 10 taps, after a short "Ad break" screen so a fast-tapping player doesn't hit the ad by accident |
| Rewarded | "Watch ad for +50 points", given only when the player actually earns the reward |
